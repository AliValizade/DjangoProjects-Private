# Django Projects

A collection of web projects developed with **Python and Django**, covering different aspects of backend and web application development.

## 📌 Overview

This repository contains several Django projects created for learning, experimentation, and practical software development.

The projects demonstrate different concepts including:

* Django application architecture
* Database integration
* Authentication and user management
* CRUD operations
* Web application development
* PostgreSQL
* Docker and Docker Compose
* Project configuration and deployment concepts

## 🚀 Projects

### 🛒 FitzoneShop

An e-commerce-oriented Django project demonstrating concepts related to online stores and product management.

### 🥤 PurposefulDrink

A Django web application project built around a product-oriented business concept.

### 📚 Bookstore

A Django-based bookstore project demonstrating web application and database concepts.

### 🏋️ FitZone

A web application project related to fitness and gym management concepts.

### 📝 Notes

A Django project focused on creating and managing notes, providing a practical example of CRUD-based web development.

### 🐘 PostgreSQL + Docker

A Django development environment demonstrating the use of **PostgreSQL** together with **Docker** and **Docker Compose**.
